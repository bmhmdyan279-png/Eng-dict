# فرهنگ واژه‌های تخصصی مهندسی

به فرهنگ آنلاین واژه‌های تخصصی مهندسی خوش آمدید.  
این پروژه با هدف گردآوری و ارائهٔ واژگان فنی تمام رشته‌های مهندسی ساخته شده و رایگان در دسترس همگان است.
